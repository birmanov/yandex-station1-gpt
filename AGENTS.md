# Правила работы с проектом

- Основной репозиторий: `birmanov/yandex-station1-gpt`. Документация для владельца — на русском.
- Целевая платформа: Станция 1, Android 6 / API 23 / ARM64. Не предполагать совместимость рецептов для Linux-моделей.
- Рабочая Алиса должна сохраняться. `BOOT_LAUNCHER=alice` не заменяет выбранное Android-приложение HOME: проверять реальный возврат из лаунчера без окна выбора.
- При диагностике обрывов читать `docs/WIFI-RECOVERY.md`: штатный Android управляет сетью, а профиль возврата AliceBridge отключён. Не создавать новый жёсткий домашний профиль агента автоматически и не отключать сам агент вместе с защитой OTA.
- Не выполнять заводской сброс, запись boot, обновление прошивки или отключение защиты OTA без отдельного согласия владельца.
- Эксперименты должны быть изолированы и обратимы. Не объявлять прототип развёрнутым до чтения состояния реального устройства.
- Пароли, токены, SSH-материалы, cookies и пользовательские сетевые профили не входят в Git. Не копировать рабочий scratch-каталог целиком.
- Не сохранять в общих инструкциях домашние SSID, адреса устройства, MAC, личные пути и исходные логи. Для примеров использовать явные заглушки.
- Код и тесты переносить по явному списку файлов после проверки происхождения и лицензии. Не включать чужие APK, прошивки и инструменты сборки в репозиторий.
- Для изменений авторизации нужны тесты CSRF/origin, восстановления после завершения процесса, выхода, смены пароля, конкурентных операций и ошибок записи. Проверка входа не должна требовать пароль владельца: использовать изолированные тестовые учётные данные.
- Файлы сессий приватные. Ошибка ограничения прав или записи не должна молча ослаблять защиту либо восстанавливать отозванный вход.
- На Android 6 старый ART-кэш может сохранять смещения из тестовых JAR. Для изменившегося класса использовать свежий путь артефакта и согласованную сборку тестов.
- Записывать текущий статус в `docs/STATUS.md`: реализовано, проверено, не проверено, не развёрнуто. Не подменять фактические результаты обещаниями.
