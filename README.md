# Yandex Station 1 — GPT Bridge

Экспериментальный проект для **Яндекс Станции первого поколения**: удобное переключение между штатной Алисой и голосовым GPT.

> Голосовой GPT-мост ещё не реализован. Работающий лаунчер и наличие root сами по себе не означают поддержку GPT через микрофоны Станции.

## Цель

На телевизоре выбрать «GPT», задать вопрос через микрофоны Станции, услышать ответ и вернуться к Алисе. Первый прототип — с явным запуском кнопкой; постоянное прослушивание и голосовое переключение не входят в начальный этап.

## Проверенное устройство

- Яндекс Станция 1, семейство `tulip`.
- Android 6.0.1 / API 23, ARM64.
- На проверенном экземпляре доступны root SSH, HDMI и устройства ALSA capture/playback.
- Захват речи с нужных микрофонов, освобождение аудиоустройств и переключение звукового фокуса **ещё не проверены**.

Инструкции для Linux-Станций 2 / Миди / Лайт нельзя автоматически переносить на эту модель.

## Текущее состояние

На пользовательском устройстве настроены Projectivy, Zona, SmartTube, переход в штатную Алису и настройки Android. Владелец подтвердил работу Алисы после смены Wi-Fi. Голосовой GPT пока отсутствует.

Исправление повторного входа в веб-пульт находится в работе и **не установлено**: замечания независимой проверки устранены в коде кандидата, но он ещё не прогонялся на устройстве. Это не готовый релиз.

Подробнее: [состояние работ](docs/STATUS.md), [план](docs/ROADMAP.md), [безопасность](SECURITY.md).

## Что хранится здесь

Документация, исходники пульта, тесты, очищенные настройки и результаты экспериментов. Работающая версия отделена от незавершённых изменений. Двоичные файлы приложений и пользовательские данные устройства не загружаются.

**Никогда не добавлять** пароли Wi-Fi, API-ключи, SSH-ключи, cookies, файлы авторизации, пользовательские конфиги устройства и сырые журналы.
