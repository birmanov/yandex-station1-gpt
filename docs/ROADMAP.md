# План разработки

## 0. Воспроизводимая основа

- Сохранить очищенные исходники и сведения об их происхождении.
- Описать сборку для Android 6 / API 23.
- Отделить стабильную версию от экспериментальной.
- Завершить проверку сохранения входа в пульт, включая конкурентные операции и ошибки файловой системы.
- Не менять рабочую систему владельца ради подготовки репозитория.

## 1. Проверка аудиотракта

| Эксперимент | Условие успеха | Основной риск |
| --- | --- | --- |
| Запись | С разрешения владельца получена разборчивая речь с нужных микрофонов | Устройство занято штатными процессами или выбран неверный PCM |
| Воспроизведение | Тестовый ответ слышен через динамики, затем штатный звук восстанавливается | Конфликт аудиофокуса и маршрутизации |
| Возврат Алисы | После запуска и завершения эксперимента Алиса снова отвечает | Зависшие процессы, неосвобождённый микрофон |

Для каждого эксперимента нужны команды запуска/остановки, фактический результат и восстановление. Не записывать разговоры в репозиторий.

## 2. Минимальный GPT-режим

Предварительная архитектура, ещё не реализована:

`Кнопка GPT → явная запись вопроса → STT → LLM → TTS → воспроизведение → возврат Алисы`

На первом этапе тяжёлую обработку можно вынести на компьютер в локальной сети. Возможность переноса частей на саму Станцию определяется аудиоэкспериментами, а не предполагается заранее.

Критерии: явный индикатор записи, отмена, ограничение длительности, отсутствие секретов в журнале, возврат Алисы при ошибке сети или провайдера.

## 3. Удобное управление

- Карточка GPT в лаунчере и управление стрелками/OK.
- Переключение в Алису одной командой пульта.
- Контекст диалога и начало нового разговора.
- Предсказуемое восстановление после сбоя.

Голосовая команда переключения и непрерывный диалог — последующий этап. Совместимость микрофона Bluetooth-пульта проверяется отдельно с реальным устройством.
