# Состояние проекта

Контрольная точка: 10 ноября 2026 года. Это состояние последней проверки, а не обещание доступности устройства в любой момент.

## Подтверждено на устройстве владельца

- Станция 1: Android 6.0.1, API 23, ARM64; сборка `MOB30J.20261013`.
- Работает root SSH с аутентификацией по ключу.
- Настроен Projectivy с карточками: Zona → SmartTube → Алиса → Настройки Android.
- Штатная Яндекс Станция выбрана Android-приложением HOME по умолчанию; возврат из лаунчера проверен.
- После переноса исправлен сохранённый домашний профиль AliceBridge: старая рабочая сеть больше не должна подменять текущую. Последовательные проверки на подключённом устройстве прошли; защита OTA оставалась `protected`.
- Владелец подтвердил, что Алиса нормально отвечает голосом.
- Последняя проверенная установленная версия веб-пульта: `2.0.0`. Кнопки VPN скрыты, кнопка лаунчера открывает Projectivy.

## Веб-пульт: работа не завершена

Проблема: при перезапуске сервера сессии в памяти теряются и требуется повторный вход.

Локальный прототип сохраняет сессии и задаёт срок 30 дней. На Android прошли базовые сценарии, включая отдельные процессы создания и восстановления, HTTP-команду после восстановления, CSRF/origin, последовательный выход и смену пароля.

Независимая проверка обнаружила блокирующие замечания:

1. Конкурентная смена пароля и выдача/сохранение сессий.
2. Недостаточная проверка результата ограничения прав на файлы.
3. Согласованность памяти и диска при ошибке записи отзыва сессии.

Попытка дополнительной доработки была прервана. Её локальные изменения требуют повторной проверки. **Прототип не развёрнут и не считается безопасным релизом.** В этом начальном коммите исходников прототипа нет.

## GPT: не реализовано

- Не проверен фактический захват речи с нужного микрофонного тракта.
- Не реализовано безопасное переключение Алиса ↔ GPT.
- Не выбран и не подключён LLM/STT/TTS-провайдер.
- Не проверен диалог с прерыванием ответа и возвратом Алисы после ошибки.
