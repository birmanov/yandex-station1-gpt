# GPT-режим Станции 1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Кнопка «GPT» в веб-пульте записывает вопрос микрофонами Станции, получает ответ от OpenAI (STT → chat → TTS) и озвучивает его динамиками, после чего Алиса снова активна.

**Architecture:** Новый модуль `GptSession` внутри процесса `StationRemote` (вариант A спеки): state machine в своём потоке, аудио за интерфейсами `AudioIn`/`AudioOut` с реализациями `AndroidAudio` и `AlsaAudio`, тонкий REST-клиент `OpenAiClient` без библиотек. Весь код в `experiments/gpt-mode/src/`, тесты в `experiments/gpt-mode/tests/`, запускаются на ПК (JDK 17, `--release 7`) без Android; аудио и TLS подтверждаются спайком на устройстве.

**Tech Stack:** Java 7 (javac `--release 7`), Android 6 / API 23 hidden API через reflection, `HttpsURLConnection`, `com.sun.net.httpserver` только в тестах, D8/R8 8.3.37 для DEX.

**Spec:** `docs/superpowers/specs/2026-11-12-gpt-mode-design.md`

## Global Constraints

- Исходники компилируются `javac --release 7 -Xlint:-options -encoding UTF-8`; без лямбд, без `java.nio.file`, без сторонних JAR.
- Тесты на ПК — классы с `main` и `require()` по образцу `experiments/session-persistence/tests/SessionPersistenceCheck.java`; никакого JUnit. Класс `StationRemote` в тестах ПК не инстанцируется (его конструктор требует Android).
- В журнал не попадают: ключ, тела запросов/ответов, текст вопроса/ответа, аудио. Только шаг, HTTP-код, длительность.
- Файлы `gpt.properties*`, `openai-ca.pem`, записи и журналы устройства — вне Git (`.gitignore`).
- Адреса устройства, SSID, пути владельца в документации заменяются заглушками.
- Любой выход из сессии, включая исключение, вызывает `AliceControl.release()`.
- Новый код не переносится в `remote/` и не ставится на устройство в рамках этого плана; база для интеграции — `experiments/session-persistence/src/StationRemote.java` (кандидат `2.0.0-local.2`).
- Коммиты — в ветке `gpt-mode`, с строкой `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. Ответ TTS от OpenAI длиной 0 байт или с нечётным числом байт (битый PCM) — ожидание: сообщение «Пустой ответ озвучки», `idle`, Алиса возвращена; тест в Task 5.
2. STT вернул пустую строку или только пробелы (шум без слов) — ожидание: «Ничего не услышал», chat не вызывается; тест в Task 5.
3. `stop` пришёл в `thinking`, когда HTTP-запрос уже ушёл — ожидание: результат запроса отбрасывается, озвучка не начинается, `idle`; тест в Task 5.
4. Ответ `/v1/chat/completions` с `finish_reason=length` или без `choices` — ожидание: обрезанный текст озвучивается как есть; отсутствие `choices` даёт «Неверный ответ сервиса»; тест в Task 4.
5. Ключ с пробелами/переводом строки в конце файла (скопирован с лишним символом) — ожидание: `GptConfig` обрезает пробельные символы, `configured=true`; тест в Task 2.

### Task 5: `GptSession`

**Files:**
- Create: `experiments/gpt-mode/src/Cancel.java`, `AudioIn.java`, `AudioOut.java`, `AliceControl.java`
- Create: `experiments/gpt-mode/src/GptSession.java`
- Test: `experiments/gpt-mode/tests/GptSessionCheck.java`

**Interfaces:**
- Consumes: `GptConfig`, `OpenAiClient`, `WavCodec`, `MiniJson.quote`.
- Produces:
  - `interface Cancel { boolean requested(); }`
  - `interface AudioIn { byte[] record(int maxMillis, int silenceMillis, int silenceRms, Cancel cancel) throws Exception; }` — PCM16 моно 16 кГц; пустой массив, если речи не было.
  - `interface AudioOut { void play(byte[] pcm, int sampleRate, Cancel cancel) throws Exception; }`
  - `interface AliceControl { void acquire() throws Exception; void release(); }`
  - `GptSession(GptConfig cfg, AudioIn in, AudioOut out, OpenAiClient api, AliceControl alice, ScheduledExecutorService scheduler)`; `enum State { IDLE, LISTENING, THINKING, SPEAKING, ERROR }`; `synchronized void start()` — `IllegalStateException`, если не `IDLE`/`ERROR` или `!cfg.configured()`; `void stop()`; `void cancel()`; `synchronized void reset()` — `IllegalStateException` вне `IDLE`/`ERROR`; `State state()`; `String stateJson()` — объект из спеки §3 (`configured, state, question, answer, error, since`), `answer` обрезан до 2000 символов; `void awaitIdle(long millis)` для тестов.
  - Сообщения: «Ничего не услышал», «Пустой ответ озвучки», «Ключ отклонён» (из `ApiError`), «Превышено время ожидания» (сторожевой таймаут), для прочих `ApiError`/`IOException` — `e.getMessage()`.

- [ ] **Step 1: Написать падающий тест `GptSessionCheck`** с фальшивками (`FakeAudioIn` отдаёт заданный PCM с задержкой; `FakeAudioOut` фиксирует воспроизведённые байты и частоту; `FakeAlice` считает `acquire`/`release`; `OpenAiClient` подменяется подклассом с переопределёнными `transcribe`/`chat`/`speak`). Сценарии, каждый — отдельный метод:

```java
happyPath();        // start → LISTENING → THINKING → SPEAKING → IDLE; out.played == tts bytes @ 24000; alice.released == 1; stateJson содержит question и answer
noSpeech();         // record → пустой массив: error "Ничего не услышал", chat не вызван, release == 1
emptyStt();         // transcribe → "  ": то же сообщение, chat не вызван
emptyTts();         // speak → byte[0] или 3 байта: "Пустой ответ озвучки", IDLE, release == 1
stopWhileListening(); // record видит cancel.requested() → возвращает накопленное; дальше по цепочке
stopWhileThinking(); // chat блокируется на 500 мс, stop() во время него → speak не вызван, IDLE, release == 1
stopWhileSpeaking(); // play видит cancel → IDLE
cancelAnywhere();   // cancel() из THINKING → IDLE без озвучки
watchdog();         // cfg.watchdogMillis = 300, chat спит 2 с → ERROR "Превышено время ожидания", release == 1, speak не вызван
apiKeyRejected();   // transcribe бросает ApiError(401) → ERROR "Ключ отклонён"; cfg.configured() остаётся true
releaseOnException(); // acquire() бросает → ERROR, release вызван ровно 1 раз; record бросает → то же
startTwice();       // второй start() в LISTENING → IllegalStateException; start() из ERROR разрешён
historyLimit();     // historyTurns = 2, три вопроса подряд → chat получает ≤ 2 пары
resetClearsHistory(); // reset() в IDLE → следующий chat без истории; reset() в LISTENING → IllegalStateException
unconfigured();     // configured() == false → start() бросает, состояние IDLE
```
