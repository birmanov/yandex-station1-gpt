# Настройки Projectivy владельца

Очищенный снимок настроек Projectivy 4.73 для Android 6. Исходные значения прочитаны с действующего устройства; сами настройки при экспорте не менялись.

## Главный экран

Категория **«Главное»**, слева направо:

1. **Zona** — `mobi.zona`.
2. **YouTube / SmartTube** — `org.smarttube.stable`.
3. **Алиса** — `ru.yandex.quasar.app`.
4. **Настройки Android** — `com.android.settings`.

Системная локаль — `ru-RU`; общий размер карточек — `1.5`, масштаб категории — `0.8`. Лишние встроенные категории скрыты. Android HOME и штатный запуск оставлены за Яндекс Станцией.

## Файлы

- `projectivy-profile.json` — читаемое описание порядка, подписей и настроек.
- `preferences.overlay.xml` — только три проверенных ключа SharedPreferences: размер карточек, список категорий и подписи приложений.

Не экспортированы Firebase/аналитические идентификаторы, история запусков, время использования, кэш фоновых картинок, внутренние пути к пользовательским значкам и любые учётные данные. Неиспользуемая подпись старого Couchy также исключена.

## Восстановление

Это **не штатный файл импорта Projectivy** и не полная резервная копия данных приложения.

Для ручного восстановления можно создать категорию «Главное», добавить четыре приложения и расположить их в указанном порядке; остальные категории скрыть.

Для восстановления по root потребуется отдельно согласованная операция:

1. Проверить версию Projectivy и наличие перечисленных пакетов.
2. Сделать приватную копию текущего `com.spocky.projengmenu_preferences.xml` **вне Git**.
3. Убедиться, что процесс лаунчера действительно остановлен. Одного успешного ответа `am force-stop` может быть недостаточно.
4. Слить три ключа из overlay с актуальным XML, сохранив все остальные ключи и владельца файла. **Не заменять весь файл приложения этим коротким overlay.**
5. Учесть старую `.xml.bak`, которая может восстановить прежние значения, и иметь проверенный путь отката.
6. После запуска прочитать настройки повторно и проверить экран, порядок и открытие Алисы/Android Settings.

В текущем профиле пользовательская категория имеет ID `579`. При слиянии с другим профилем проверить возможное совпадение ID, а не перезаписывать чужую категорию вслепую. Числа action ID приложений соответствуют знаковому Java `String.hashCode()` их package name.

Локаль и выбранный Android HOME не восстанавливаются простой записью настроек Projectivy. Для HOME в системном выборе нужно закрепить Яндекс Станцию с вариантом «Всегда». Автоматического применения к устройству в этом экспорте нет.
