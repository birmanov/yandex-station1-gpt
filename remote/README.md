# Исходники установленного веб-пульта

Здесь сохранена версия сервера `2.0.0`, которая работает на Станции владельца. Это импорт текущего состояния, **не установка обновления**.

## Состав

- `src/StationRemote.java` — HTTP/WebSocket, вход и команды Android.
- `src/VlessLink.java` — вспомогательный разбор VPN-ссылок из upstream; сохранён для совместимости сборки, хотя кнопки VPN в интерфейсе скрыты.
- `src/index.html` — полученная с устройства страница пульта без кнопок VPN.
- `src/remote-start.sh` — полученный с устройства запуск и наблюдение за службой.
- `build.py` — сборка DEX и архива полезной нагрузки, импортированная из upstream.
- `LICENSE.upstream` — лицензия исходного проекта; авторство и изменения описаны в `../THIRD_PARTY.md`.

Кнопка «Лаунчер» открывает Projectivy. По умолчанию сохраняется `BOOT_LAUNCHER=alice`. Не включайте автозапуск ТВ-лаунчера вместо Алисы, если нужно сохранить штатный голосовой режим.

## Проверка соответствия устройству

Исходники собраны JDK 17 и D8/R8 8.3.37. `classes.dex` из новой сборки **побайтно совпал** с DEX установленного пульта.

SHA-256 проверенного `classes.dex`:

```text
06aea2a367e0bf16a4711ea347780af844e0f09fbd21f4b5ecdcc26b0f63afa7
```

Это проверка соответствия источника установленной версии, а не независимый аудит безопасности и не гарантия отсутствия ошибок.

## Сборка

Нужны Python 3.10+, JDK 17 и Google D8/R8 8.3.37. Задайте `JAVA_HOME` и `R8_JAR`, затем из корня репозитория:

```sh
python remote/build.py
```

Результаты — `remote/dist/station-remote.jar` и `remote/dist/payload.tar.gz`. Эти артефакты и локальные инструменты исключены из Git. Шаблоны установщиков не импортированы, поэтому эта копия сборки не создаёт готовый самостоятельный установщик.

**Сборка ничего не отправляет на Станцию.** Обновление службы — отдельная операция с резервной копией и проверкой состояния.

## Известное ограничение

В этой установленной версии вход живёт в памяти сервера и теряется при его перезапуске. Доработка сохранения входа хранится отдельно в `../experiments/session-persistence/` и не является частью этой версии.

Пароли, `auth.properties`, cookies и файлы сессий не включены. Пульт работает по локальному HTTP; не публикуйте его порт в интернете.
